# SDE Learning Repository

A personal repository to track my journey as a Software Development Engineer.

This repository contains my learning notes, concepts, resources, practice problems, projects, and references across different areas of Software Engineering and AI.

## Repository Structure

The `main` branch contains only the repository overview and user guide.

Learning content is maintained in separate branches based on the topic.

| Branch              | Content                                                                     |
| ------------------- | --------------------------------------------------------------------------- |
| `dsa`               | Data Structures & Algorithms, problem solving, patterns and notes           |
| `os`                | Operating Systems concepts and notes                                        |
| `system-design`     | System Design concepts, architecture, scalability and design patterns       |
| `database`          | SQL, PostgreSQL, database concepts, indexing, transactions and optimization |
| `computer-networks` | Networking fundamentals, protocols, HTTP, TCP/IP, etc.                      |
| `backend`           | Backend development, APIs, authentication, architecture and best practices  |
| `frontend`          | Frontend development, React, Next.js, TypeScript and related concepts       |
| `devops-cloud`      | Docker, CI/CD, cloud, deployment and infrastructure                         |
| `ai`                | AI, LLMs, RAG, agents, AI engineering and related concepts                  |
| `projects`          | Learning projects, experiments and implementations                          |

## How to Use This Repository

Clone the repository:

```bash
git clone <repository-url>
cd <repository-name>
```

Switch to the topic you want to study:

```bash
git checkout dsa
```

or:

```bash
git checkout system-design
```

To see all available branches:

```bash
git branch -a
```

## Branch Philosophy

Each branch represents an independent learning track.

For example:

```text
main
 ├── dsa
 ├── os
 ├── system-design
 ├── database
 ├── computer-networks
 ├── backend
 ├── frontend
 ├── devops-cloud
 ├── ai
 └── projects
```

The `main` branch should remain lightweight and primarily act as the **entry point and navigation guide**.

## What Goes Into Each Branch?

Each learning branch can contain:

* `README.md` — topic roadmap and navigation
* `notes/` — detailed learning notes
* `resources/` — useful articles, courses and references
* `problems/` — practice problems
* `examples/` — code examples
* `projects/` — topic-specific implementations

Example:

```text
dsa/
├── README.md
├── notes/
├── problems/
├── patterns/
├── resources/
└── examples/
```

## Learning Approach

The goal is not only to collect notes, but to build practical understanding through:

**Learn → Practice → Implement → Revise → Document**

This repository will continuously evolve as I learn new concepts and technologies.
